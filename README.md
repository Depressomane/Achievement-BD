# ballsdex-achievements

Achievement package for Ballsdex v3.
This is [Mitoopo's Achievement-BD package](https://github.com/Mitoooooooopo/Achievement-BD), but I updated it to be compatible with Ballsdex v3.

## Installation

Add the following into your `config/extra.toml` file.

```toml
[[ballsdex.packages]]
location = "git+https://github.com/seiftheman/ballsdex-achievements.git#main"
path = "achievements"
enabled = true
```
